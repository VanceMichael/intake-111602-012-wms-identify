# 资料服务接口

资料源支持单段 HTTP Range，返回 Content-Range 和内容摘要 ETag。If-Match 可以限定本次范围读取的来源版本，版本不符返回 412，越界返回 416。该行为只负责传输，不替接收应用决定领域对象是否完整。

GetFeatureInfo 的图层可查询状态由来源能力决定。空命中为成功的空 FeatureCollection，不可查询层返回 LayerNotQueryable；像素参数随 WMS 版本校验。

WMS 查询参数依据来源版本选择 I/J 或 X/Y。本地 /map/context 与 /map/operations 是已有编辑器的实际操作上下文，不属于 WMS 标准；GetFeatureInfo 入口为 /wms，参数顺序不应影响业务身份。EPSG:4326 在 WMS 1.3.0 下按纬度、经度轴序传输。

查看器按操作领取资料时会固定操作发起时的地图版本，不重新读取当前画面。版本决定像素参数（I/J 或 X/Y）和坐标系参数（CRS 或 SRS）；若来源能力的版本与地图版本不同，坐标范围按各自轴序换算后再查询，并在凭据中记录此差异。能力文档单独作为原件保存，凭据保留其摘要。

本地服务的资料入口为 `/map/context`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。

一次点选可能涉及多个查询图层，各层结果分别记录：可以查询且命中、可以查询但该点没有命中、来源标明不可查询、以及请求失败。不可查询不等于空命中，后者的应答仍是成功的 FeatureCollection。任何一层的返回都只说明所点像素位置的情况，不能当作该图层的全量资料。
