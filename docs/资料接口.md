# 资料服务接口

WMS 查询参数依据来源版本选择 I/J 或 X/Y。本地 /map/context 与 /map/operations 是已有编辑器的实际操作上下文，不属于 WMS 标准；GetFeatureInfo 入口为 /wms，参数顺序不应影响业务身份。EPSG:4326 在 WMS 1.3.0 下按纬度、经度轴序传输。

本地服务的资料入口为 `/map/context`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
